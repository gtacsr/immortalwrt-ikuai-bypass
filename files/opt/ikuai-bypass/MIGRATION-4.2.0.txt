iKuai Bypass 配置迁移说明：4.4.x  →  4.2.0
=================================================
本镜像内置 v4.2.0（官方说明：兼容爱快 3.x 的最后一个稳定版本）。
仓库里原有 config.yml 是按 4.4.x 模板写的，直接拿到 v4.2.0 上会有 4 处问题，
其中第 2 条会让「下一跳分流」完全不生效。

1) ip-group / ipv6-group / custom-isp 的条目名
   4.4.x :  - tag: 国内
   v4.2.0:  - name: 国内
   说明：v4.2.0 用 name: 作为分组名，写 tag: 会被当成空名字，
         stream-ipport 里 ip-group: 国内 就索引不到分组。
   custom-isp 在 v4.2.0 里 name 是名称、tag 是「规则备注后缀」，两者都要有。

2) 分流模块从配置项改成命令行参数（最容易踩的一条）
   4.4.x :  配置里写 mode: ipgroup
   v4.2.0:  启动时传 -m 参数，取值：
             ispdomain  自定义运营商 + 域名分流（默认）
             ipgroup    ip 分组 + 端口分流（下一跳）
             ipv6group  IPv6 分组
             ii         ispdomain + ipgroup（本镜像默认）
             ip         ipgroup + ipv6group
   说明：init 脚本现在启动的是
             ikuai-bypass -r cronAft -m ii -c /opt/ikuai-bypass/config.yml
         需要改模块：改 /etc/init.d/ikuai-bypass 里的 IKB_MODULE，或直接命令行指定。

3) stream-ipport 删掉 4 个字段
   4.4.x 才有、v4.2.0 没有：src-addr-inv、dst-addr-inv、prio、protocol
   说明：v4.2.0 忽略未知字段，但语义不会生效，留着只会误导。
   补充（已核对 4.4.110 源码）：这 4 个字段在 4.4.110 里也没有被解析——
   config.go 的 StreamIpPort 结构体只有 type/opt-tagname/interface/nexthop/
   src-addr/src-addr-opt-ipgroup/ip-group/mode/ifaceband，
   AddStreamIpPort 的入参签名与 v4.2.0 完全相同。
   也就是说它们是模板残留，删掉不丢任何功能。

3.5) 同样属于模板残留、两个版本都不读的顶层键
   ikuai-url-ignore-cert、proxy、run-mode、mode
   （4.4.110 里模块选择同样是命令行 -m，MaxNumberOfOneRecords 才是它真正新增的，
     作用是限制单条规则写入量——那是爱快 4.0 API 约 90KB 的限制，对 3.x 无意义）

6) IPv6 分组怎么跑（v4.2.0 没有 "-m iip" 这个组合）
   4.4.x 有 ii+ipv6 的组合值，v4.2.0 没有，所以本镜像这样处理：
     - 主服务：-r cronAft -m ii   （运营商/域名分流 + ip 分组/下一跳）
     - IPv6：init 脚本起一个独立循环，立刻跑一次 -m ipv6group，之后每 24 小时一次
   相关变量（改 /etc/init.d/ikuai-bypass 顶部）：
     IKB_MODULE          默认 ii
     IKB_RUN_IPV6        默认 1，设 0 关闭 IPv6 自动同步
     IKB_IPV6_INTERVAL   默认 86400 秒
   日志：/tmp/ikuai-bypass-ipv6.log
   手动跑一次：ikuai-bypass -r once -m ipv6group -c /opt/ikuai-bypass/config.yml

4) stream-ipport 的 mode 取值范围
   4.4.x : 支持到 6（高级模式）
   v4.2.0: 0-新建连接数 / 1-源IP / 2-源IP+源端口 / 3-源IP+目的IP
           / 4-源IP+目的IP+目的端口 / 5-主备模式
   说明：原配置的 mode: 6 已在 v4.2.0 中改为 0（单线场景无差别）。

5) 顶层去掉 4.4.x 独有字段
   ikuai-url-ignore-cert、run-mode、mode、proxy、MaxNumberOfOneRecords
   说明：v4.2.0 不认这些。代理只保留 github-proxy 一项。

其他保持不变：
   - 域名分流 stream-domain 的字段两版一致，原样保留
   - webui 端口仍为 19001（v4.2.0 默认 19000），账号 admin，密码空
   - cron / AddErrRetryWait / AddWait / github-proxy 一致

4.4.x 原版配置已留档：/opt/ikuai-bypass/config.4.4-example.yml
